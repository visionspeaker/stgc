앱을 새로 내려받는 것이 아니라, 바로가기를 놓는 것입니다. 용량을 거의 쓰지 않습니다.
먼저 크롬으로 열어 주세요.
지금은 카카오톡 같은 다른 앱 안에서 보고 계셔서 추가가 되지 않습니다.
화면 구석의 ⋮ 또는 ⋯ 를 누르고 「다른 브라우저로 열기」 → Chrome 을 골라 주세요.
